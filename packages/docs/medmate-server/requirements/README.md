# Requirements

Product requirements for medmate-server live in this directory. The `medmate-requirement` command writes them after the open questions are settled.

File name: `YYYY-MM-DD-<slug>.md`

Each spec includes:

- context
- scope
- non-goals
- behavior, including data, API, errors, and auth
- acceptance criteria
- tests to add, including the Bruno request

Implementation follows an accepted plan for that spec. Structural choices also get an ADR in `../decisions/`.
